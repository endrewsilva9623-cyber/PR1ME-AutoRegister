# PR1ME AutoRegister

Baixe a versao mais recente em **Releases** (lado direito) e execute `PR1ME-AutoRegister.exe`.

- O app **se atualiza sozinho**: ao abrir, ele verifica a ultima release aqui e baixa a nova versao automaticamente.
- Requer **Google Chrome** instalado.
- Na primeira execucao, se o **Cloudflare WARP** nao estiver instalado, ele instala sozinho (aceite o pedido de administrador do Windows).
- Seus dados ficam em `%LOCALAPPDATA%\PR1ME\data` e **nao sao apagados** nas atualizacoes.
- Se o WARP nao for instalado, o app roda normalmente, porem **sem troca de IP**.
